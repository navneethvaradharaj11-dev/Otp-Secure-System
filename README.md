# OTP Secure System

A Python-based One-Time Password (OTP) authentication simulation built to demonstrate authentication logic and practical version control using Git and GitHub.

## Project Overview

The OTP Secure System simulates a secure authentication workflow commonly used in modern login systems. It demonstrates core backend concepts such as OTP generation, expiration handling, limited verification attempts, and basic session control.

This project is intended for educational purposes and does not send real OTP messages.

## Features

* 6-digit OTP generation
* OTP expiration (60 seconds)
* Maximum of 3 verification attempts
* Numeric input validation
* OTP resend simulation
* Console-based authentication workflow

## Technologies Used

* Python 3 (Programming Language)
* Git (Version Control System)
* GitHub (Repository Hosting Platform)

## How to Run

1. Clone the repository

```bash
git clone https://github.com/navneethvaradharaj11-dev/otp-secure-system.git
```

2. Navigate to the project directory

```bash
cd otp-secure-system
```

3. Run the program

```bash
python main.py
```
