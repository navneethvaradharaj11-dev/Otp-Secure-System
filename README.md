# OTP Secure System

A Python-based One-Time Password (OTP) simulation system built for learning authentication logic and version control using Git and GitHub.

---

## Project Overview

This project simulates a secure OTP authentication workflow. It demonstrates core backend concepts such as OTP generation, expiration handling, limited login attempts, and basic session control.

The system is designed for educational purposes and does not send real OTP messages.

---

## Features

- 6-digit OTP generation
- OTP expiration (30 seconds)
- Maximum of 3 verification attempts
- Numeric input validation
- Basic login session flow
- Console-based simulation

---

## Technologies Used

- Python 3
- Git
- GitHub
